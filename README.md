# AI Prompts Library

A collection of high-quality AI prompts for various use cases.

## Categories

- **content-writing** - Blog posts, articles, social media content
- **marketing** - Ads, email campaigns, SEO
- **side-income** - Business ideas, freelance pitches, monetization strategies
- **coding** - Programming assistance, automation scripts
- **image-generation** - Midjourney, DALL-E, Stable Diffusion prompts

## Structure

```
prompts/
├── content-writing/
├── marketing/
├── side-income/
├── coding/
├── image-generation/
templates/
resources/
```

## Usage

Copy prompts into ChatGPT, Claude, or other AI tools and customize for your needs.
